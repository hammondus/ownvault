Vault name

A short label for this vault (e.g. Home, Work). It names the installed app icon and labels this vault on the lock screen and in the vault picker. Encrypted and synced, so your other devices inherit it — the server never sees it.

Install app

Install Own Vault to your device for full-screen, offline access and a home-screen icon.

On iOS, add it to your Home Screen from Safari:

  1. Tap the Share button (the square with an upward arrow).
  2. Choose Add to Home Screen.
  3. Tap Add.

Other iOS browsers can't install to the Home Screen — open this page in Safari first.

The Home Screen app has its own storage, separate from Safari. It starts with no vault, so connect it there using the setup code below and your master password.

✓ Own Vault is installed on this device.

Sync

Sync across devices through the Go server that served this app. Everything is end-to-end encrypted — the server only ever stores ciphertext. The server is also this vault's off-device backup, so sync is always on; the app still works with the server unreachable and catches up when it returns.

Backup

The export is fully encrypted — it can only be opened with the master password that made it. Keep a copy somewhere safe; browser storage can be cleared at any time.

Import from CSV

Bring passwords across from another password manager or browser (Chrome, Edge, Firefox, Safari, Bitwarden, 1Password, LastPass, KeePass) using its CSV export. Imported entries are added to this vault; nothing existing is changed.

⚠️ A CSV export holds your passwords in plain text. Delete the file — and empty the bin — as soon as the import is done.

Emergency recovery sheet

Print your critical entries — the rarely changing, must-not-lose ones like crypto seed phrases, master passwords, and 2FA backup codes — onto paper. An offline last resort that device failure, ransomware, or lost access can't touch. Mark an entry as critical from its Edit screen.

⚠️ The sheet shows passwords in plain text. Printers (especially shared or networked ones) can retain copies — use a printer you trust, store the paper somewhere physically secure, and shred old copies.

Full re-encrypt

For suspected compromise. Changing the master password only re-wraps the vault key — anyone who copied your vault and knew the old password already has that key. This generates a fresh vault key, re-encrypts every entry with it, and wraps it under a new master password. Everything happens on this device; the server only ever sees the new ciphertext.

⚠️ Your other devices will need the new master password, and any old backup files stay openable with the old one — export a fresh backup afterwards and destroy the old ones.

Appearance

Remove from this device

Deletes this vault and its settings from this browser. Other vaults on this device are untouched; removing the last vault returns the browser to a first-run state. Only this device is affected — the server's copy and your other devices keep everything.

⚠️ If this vault doesn't sync, or has unsynced changes, they are gone for good — sync or export a backup first. The installed app icon can't remove itself; delete it from your browser or home screen afterwards.
